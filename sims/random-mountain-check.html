These tests check the growth rule in random-mountain-growth.js, the math behind the sim. Press the button; it takes a few seconds. The "Exact odds" tests are random, so a correct program still fails one of them about 1 time in 1000. If one fails, press the button again.

Compare with a run of your own

import random
random.seed(1)
h = runsim(numsteps = 50)
random.seed(1)                                  # the same u's runsim used
u = [random.random() for _ in range(50)]
print(u)
print(h)
