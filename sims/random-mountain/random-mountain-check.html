Random mountain: check page

These tests check the growth rule in random-mountain-growth.js, the math behind the sim. Press the button; it takes a few seconds. The tests use fixed random seeds, so they do the same thing every time.

Compare with a run of your own

In Python, copy the runsim function from randmountain.py (or randonesidedmountain.py) into a new file, and add below it: 

import random
random.seed(1)
h = runsim(numsteps = 50)
random.seed(1)                                  # the same u's runsim used
u = [random.random() for _ in range(50)]
print(u)
print(h)
