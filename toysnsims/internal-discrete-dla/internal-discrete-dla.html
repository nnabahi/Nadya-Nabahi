About the model

(The simple explanation is coming.)

The model [1]. Fix a lattice (the line \mathbb{Z}, the square grid \mathbb{Z}^2 or any tiling of the plane, the cubic grid \mathbb{Z}^3 or any tiling of space) and a source cell, the origin 0. Start with A(1) = \{0\}. Given the cluster A(n), let a particle do the simple random walk (each neighbor equally likely) from 0, and let x_{n+1} be the first cell it reaches outside A(n). Then A(n+1) = A(n) \cup \{x_{n+1}\}, so |A(n)| = n.

The ball. On \mathbb{Z}^2 and \mathbb{Z}^3 the cluster grows like a Euclidean ball: with \rho_n the radius of the ball with volume n (\pi \rho_n^2 = n in 2D, \tfrac43 \pi \rho_n^3 = n in 3D), for every \varepsilon > 0, almost surely B_{(1-\varepsilon)\rho_n} \cap \mathbb{Z}^d \subset A(n) \subset B_{(1+\varepsilon)\rho_n} for all large n [2]. The errors are much smaller than \varepsilon \rho_n: at most C \log n in 2D [3, 4] and C \sqrt{\log n} in 3D [5], with high probability. The page shows the inner radius (the nearest cell not in the cluster: on \mathbb{Z}^d every cell but the origin has a neighbor nearer the origin, so the nearest cell not in the cluster is next to it) and the outer radius (its farthest cell), and on the grids the errors \rho_n - \text{inner} and \text{outer} - \rho_n. On other tilings I know no theorem for the limit shape, so the page draws no ball there.

On the line. The cluster is always an interval \{-L, \dots, R\} with L + R + 1 = n, and the next particle leaves it on the right with chance \frac{L+1}{n+1} (gambler's ruin [9, Section XIV.2]): the shorter side is the likelier to grow. This is Friedman's urn (draw a ball, put in one of the other color) [10, 11], so the cluster stays centered: D = R - L has D/n \to 0 and D/\sqrt{n} tends to a normal law. Exactly, \mathbb{E}[D_{n+1}^2 \mid D_n] = D_n^2 \left(1 - \tfrac{2}{n+1}\right) + 1, so \mathbb{E}[D_n^2] = \tfrac{n+1}{3} for n \ge 2. Here \rho_n = \tfrac{n-1}{2}, the outer error is |D|/2 and the inner error |D|/2 - 1, so both are of order \sqrt{n}, much bigger than in 2D and 3D, and the outer error's root mean square is exactly \sqrt{(n+1)/12} (the dashed line on the chart).

Early or late. Cell x joined as cell number m; a perfect ball with m cells has radius \rho_m. The color is |x| - \rho_m: positive (red) means the cluster reached x early. This is the picture whose fluctuations converge to a Gaussian free field [6].

Exact jumps. A particle deep inside the cluster is far from every cell that could stop it. If the ball of cells at most r steps from it lies in the cluster, the walk can't stop before leaving that ball, so the page jumps straight to the cell where it first leaves, drawn from the exact exit law of the ball (worked out once by solving the linear system for the walk's Green's function in the ball [7, Section 4.6]). By the strong Markov property [8, Theorem 1.4.2] the result is exactly the same as taking every step; the model check page tests it. On a Penrose tiling, which never repeats, every step is taken.

Random numbers. Move j of particle p uses a uniform number made from the seed, p and j. So particle p walks the same way however many come after it, and going from n to n + 1 particles only adds a cell.
