Lattice Path Counting: Check Page

These tests check path-counting-math.js, the math behind the sim, against things worked out separately: binomial coefficients, every path listed one by one on small grids, and the bell curve. Press the button; it takes a second or two. The test of u(…) uses a statistical test, so a correct program fails it about 1 time in 1000 seeds (it always uses the same seed here, so it either always passes or always fails).
