About the model

Pick points on the line, the roots, and multiply one factor for each:

f(x) = \prod_n \left(1 - \frac{x}{R(n)}\right).

Then f is 0 at every root, and f(0) = 1. If the roots are evenly spaced, 1 apart, f is exactly a sine wave. Here the gaps between roots are random, and the sine wave bends: some humps ("lobes") grow tall, others flatten.

The roots are stationary: the picture looks the same, on average, wherever you stand on the line. So the origin is not a root; it falls at a random place inside some gap.

Things to try: slide δ down to 0 and watch the sine wave appear (dashed: the sine wave with the same first root and the same mean gap); type your own gap set, like {1, 3} or 1 + δu^3; switch to the jittered lattice; press Play to collect histograms of the lobes from many samples; drag the picture or zoom out to see far away.

The function. With roots \dots < R(-2) < R(-1) < 0 < R(0) < R(1) < \dots,

f(x) = \prod_{n=-N}^{N-1} \left(1 - \frac{x}{R(n)}\right), \qquad f(0) = 1.

Sine wave. If every gap is 1, the roots are n + a with 0 < a < 1, and as N \to \infty Euler's product \sin \pi z = \pi z \prod_{n \ge 1} (1 - z^2/n^2) [1] gives

f(x) = \frac{\sin \pi (a - x)}{\sin \pi a}.

So even with equal gaps, the height 1/|\sin \pi a| is random: the wave is tall when a root lands near 0. With every gap equal to m, replace \pi by \pi/m; that is the dashed curve.

Walk. The gaps R(n) - R(n-1) are independent and uniform on the typed set G, except the gap covering 0. For stationarity that one is size-biased: it has length g with probability proportional to g, and 0 is uniform inside it. This is the stationary renewal process, and the size-biasing is the "inspection paradox" [2, 3]. For G = [1-d, 1+d] the covering gap is

L = \sqrt{4du + (1-d)^2}, \qquad u \sim \mathrm{Uniform}[0, 1].

Jittered lattice. R(n) = n + s + U(n), with U(n) uniform on the typed set and one shift s uniform on [0, 1), which makes it stationary.

Mirror. Roots at 0 and \pm r(k), with r(k) a walk with gaps uniform on G, so f(x) = x \prod_k (1 - x^2/r(k)^2) is odd, and f'(0) = 1. It can't be stationary, since 0 is always a root.

Random numbers. Gap n is g(u_n) for a fixed uniform number u_n (from the seed). A finite set picks element \lfloor m u_n \rfloor, an interval [a, b] gives a + (b - a) u_n. Changing G keeps every u_n, so the curve moves continuously.

Peaks. Between two neighboring roots, f'/f = \sum_n 1/(x - R(n)) falls from +\infty to -\infty, and its derivative -\sum_n 1/(x - R(n))^2 is negative, so each lobe has exactly one peak x_n, found by bisection. The lobe areas I_n use 20-point Gauss–Legendre quadrature [4]. f is computed as a sum of logarithms, so very large or very small values don't overflow.

Truncation. Only N roots on each side are used, so the picture is accurate only well inside the roots; the sim warns when the window gets close to the last root. With equal gaps the error near x is about x^2/N.

F. As in the Desmos version, F is the integral of f, minus its average over the window (in place of the limit over the whole line).
