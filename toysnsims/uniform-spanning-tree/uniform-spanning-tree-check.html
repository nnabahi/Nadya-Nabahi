Uniform Spanning Tree: Check Page

These tests check the spanning tree code in js/sim-spanning.js, the math behind the sim: counting spanning trees against known counts, Wilson's algorithm against the uniform law (every spanning tree equally often), the colors against the tree (they should be independent), the path to the root against a loop-erased random walk made directly, and the distances in the tree against a plain search. Press the button; it takes about 10 to 30 seconds. The tests use fixed random seeds, so they do the same thing every time.
